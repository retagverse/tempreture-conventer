# Temperature Converter (Python)

## Overview
This project is a simple command-line Temperature Converter built using Python. It allows users to convert temperatures between Celsius and Fahrenheit through a menu-driven interface.

## Features
- Convert Celsius to Fahrenheit
- Convert Fahrenheit to Celsius
- Simple menu-based interface
- Displays results with decimal precision
- Handles invalid choices

## Technologies Used
- Python

## Sample Output

=== Temperature Converter ===

1. Celsius to Fahrenheit
2. Fahrenheit to Celsius

Choose an option: 1

Enter temperature in Celsius: 25

Result: 77.00°F
